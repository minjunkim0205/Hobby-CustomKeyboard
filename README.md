# Hobby Custom Keyboard

커스텀 키보드 관련 하우징, 보강판, 기판 자료를 정리한 저장소입니다.

## 바로가기

- [키보드](keyboards/README.md): 하우징별 자료와 공통 규격 보강판
- [기판](pcb/README.md): 기판별 설계 자료, 펌웨어, VIA/Vial 레이아웃, 드라이버, 웹 설정 링크

## 정리 구조

```text
키보드
  하우징
    보강판 파일
    하우징 설계 도면 파일
  공통 규격
    보강판 파일

기판
  기판별 폴더/
```

실제 폴더명은 영문으로 통일했고, 도면/펌웨어 같은 내부 파일 내용은 수정하지 않았습니다.
